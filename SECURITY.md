# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/youvandra/sdiqt/security/advisories/new).
Please do not open a public issue for a security problem.

Include the affected component (prover, verifier, watchtower, operator, explorer or a spec),
the commit you tested, and steps to reproduce. We aim to acknowledge a report within 48 hours.

## Scope

SDIQT runs on the QoreChain `qorechain-diana` testnet. Issues in QoreChain itself or in the
RDK should also go to the QoreChain team. If a finding touches both, tell us and we will
coordinate the disclosure with them.
